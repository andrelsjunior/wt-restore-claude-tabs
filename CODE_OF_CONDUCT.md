# Code of Conduct

## The short version

Be decent. Assume good faith. Criticise code, not people.

## Not welcome

Harassment, personal attacks, insults tied to who somebody is, publishing other
people's private information, and any other behaviour that would make a
reasonable person not want to take part.

## Scope

This applies to issues, pull requests, discussions and anywhere else the project
is represented.

## Enforcement

Report a problem by opening an issue, or privately through a
[security advisory](https://github.com/andrelsjunior/wt-restore-claude-tabs/security/advisories/new)
if it is sensitive. Maintainers may edit, hide or delete contributions that break
these rules, and may block repeat offenders.
